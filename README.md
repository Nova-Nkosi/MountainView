# MountainView Group Website

The official corporate website for MountainView Group, a holding entity integrating financial precision with technical infrastructure. One entity, two specialised divisions: MountainView Accounting and MountainView Technologies.

## Core Features

- **Dual-Division Architecture:** Distinct visual identities for Accounting (Purple) and Technologies (Blue).
- **Ambient Design:** Custom CSS floating tech art, ambient lighting orbs, and scroll-reveal animations.
- **Mobile-First UI:** Fully responsive navigation with a custom full-screen mobile overlay menu.
- **Live Chat:** Integrated Crisp chatbot across all pages for lead generation and client triage.
- **Lead Capture:** Formspree integration for the contact forms.
