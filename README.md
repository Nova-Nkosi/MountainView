# MountainView Group Website

A premium boutique accounting and digital infrastructure website for SMEs and NGOs.

## Tech Stack
- HTML5
- Tailwind CSS (via CDN)
- Vanilla JavaScript

## Structure
- `index.html` - Homepage
- `who-we-are.html` - The Firm
- `services.html` - Detailed Services
- `smes-ngos.html` - Advisory information
- `contact.html` - Formspree Contact Form
- `login.html` - Portal Login
- `dashboard.html` - Client Dashboard
- `logo.jpg` - Brand Assets

## Deployment
Automatically deployed via GitHub Pages. Any changes pushed to the `main` branch will reflect on the live site.
